# NATA Travel Agency — Checkpoint 01

First responsive visual shell for the NATA Travel Agency website.

## Included
- Responsive one-page structure
- NATA logo asset
- Navigation: Home, Tours, Our Services, About Us, Contact
- Language selector prototype: English, Spanish, French and Mandarin Chinese
- Four experience cards
- About, services and contact sections
- HTML, CSS and JavaScript separated into folders

## Run locally
Open `index.html` in a browser. For best results, use the Live Server extension in Visual Studio Code.

## Publish with GitHub Pages
1. Create a new public GitHub repository named `nata-travel-agency`.
2. Upload all files and folders in this project (not only the ZIP).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. The URL will appear in the Pages settings.

## Important notes
- The hero uses a temporary remote image URL; replace it with approved NATA photography before launch.
- Experience cards currently use visual placeholders, not final destination photographs.
- Contact email is a placeholder and must be replaced with the agency's confirmed contact address.
- The four language versions contain preliminary interface copy only. All final marketing, legal and tour content must be professionally reviewed and translated.
- This is a static prototype. It does not yet include booking, payment, CRM or form submission functionality.
