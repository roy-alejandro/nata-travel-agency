CAMBIOS
1. Se conserva la estructura desplegable mediante ventanas modales para Servicios y Nosotros.

3. Las tarjetas y las galerías de detalle ya apuntan a las rutas locales indicadas en los README de cada carpeta.
4. Se incorporan las recomendaciones y opciones personalizadas entregadas por NATA para Montaña de Colores.
5. Se incorporan las recomendaciones entregadas por NATA para Valle Sur.
6. No se han inventado imágenes: las nuevas carpetas quedan listas para que el equipo coloque sus fotografías.

IMPORTANTE PARA CARGAR FOTOS
Coloca los archivos JPG en las carpetas indicadas y conserva exactamente los nombres. La primera imagen de cada carpeta se utiliza en la tarjeta; al desplegar el contenido se muestran las dos imágenes del detalle.

SERVICIOS
Se mantiene el diseño anterior con tarjetas desplegables (no se convierten en bloques permanentes en la página).
