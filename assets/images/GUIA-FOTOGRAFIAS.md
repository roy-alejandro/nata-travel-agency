# Biblioteca fotográfica de NATA

Esta carpeta está preparada para que el equipo incorpore fotografías propias sin reorganizar el proyecto.

## Cómo reemplazar una fotografía
1. Conserva el nombre de archivo indicado en la tabla.
2. Sube la fotografía a la carpeta correspondiente.
3. Si ya existe un archivo con ese nombre, reemplázalo.
4. Confirma los cambios en GitHub. GitHub Pages actualizará la web automáticamente.

## Recomendaciones técnicas
- Formato preferido: JPG o WebP.
- Para portada: relación aproximada 16:9.
- Para tarjetas: relación aproximada 3:2 o 4:3.
- Procura que cada fotografía pese entre 200 KB y 700 KB, si la calidad lo permite.
- Evita nombres con espacios, tildes o caracteres especiales.
- Usa fotografías propias o con licencia adecuada para uso comercial.
- No incluyas imágenes de pasajeros identificables sin autorización.

Las fotografías de referencia actuales seguirán funcionando como respaldo visual mientras no se agreguen las fotografías locales. Cuando exista una fotografía local con el nombre exacto, tendrá prioridad visual.
